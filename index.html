# ADR: move the core database from MySQL to PostgreSQL
status  accepted · shipped
owner   eshan (schema design → production cutover)

## why
The roadmap called for AI-powered search: vector embeddings for natural-language
course discovery. The target was AlloyDB, Google's PostgreSQL-compatible database,
which stores embeddings and runs vector search right next to the app data.
Getting there meant getting the core database off MySQL and onto PostgreSQL first.

## decision
Migrate the core application database to PostgreSQL. Keep MySQL and PostgreSQL
in sync with a real-time CDC pipeline, validate the data before switching, and
cut production over inside a single 3-hour window.

## consequences
+ clears the path to AlloyDB embeddings and RAG course discovery (see wip/)
+ better performance, reliability and long-term scalability
- heterogeneous migration: two engines, different types and SQL, synced live
